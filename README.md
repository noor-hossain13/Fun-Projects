## 📁 Projects Included

### 1. Video Downloader
YouTube video downloader with desktop GUI application. Download videos in MP4 or extract audio as MP3.

**Location:** `./video-downloader`

**Features:**
- Download YouTube videos in MP4 format
- Extract audio to MP3
- Custom download location
- Desktop GUI with web interface
- Fast and reliable using yt-dlp

**Getting Started:**
```bash
cd video-downloader
pip install -r requirements.txt
python desktop.py
# or
.\run.bat
```

See [video-downloader/README.md](./video-downloader/README.md) for detailed documentation.
